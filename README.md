# 小説文書修正 — Novel Text Formatter

小説の文章を、指定フォーマットに沿って一括整形するWebアプリです。
テキスト欄１に文章を貼り付けると、整形結果がテキスト欄２に出力され、同時にクリップボードへコピーされます。

**サーバ不要・完全オフライン動作**。HTMLファイル1つをブラウザで開くだけで使えます。外部ライブラリ・CDN・通信は一切使用していません。

## 🔗 デモ

ブラウザですぐ試せます → **https://curemagiclab-jp.github.io/novel-text-formatter/**

## 使い方

1. `index.html` をダウンロードする(または上のデモページを開く)
2. ブラウザ(Chrome / Edge / Firefox など)で開く
3. 左の「原文」欄に文章を貼り付ける(入力中は右欄にライブプレビュー表示)
4. 中央の「整形指定」パネルで適用するルールをチェックで選ぶ
5. **「変換してコピー」** ボタン(または `Ctrl + Enter`)を押すと、整形結果が右の「整形後」欄に出力され、クリップボードにもコピーされる

## 整形ルール

各ルールはチェックボックスで個別にON/OFFできます。

| ルール | 内容 |
| --- | --- |
| "…"と"―"は必ず二連続 | 三点リーダとダッシュの奇数連続を偶数化(単独は二連に) |
| 行頭字下げ | 行頭に全角スペースを挿入。例外文字(デフォルト `「（【『≪｛`)で始まる行と字下げ済みの行はスキップ。「絵文字も例外」をONにすると絵文字(国旗・1️⃣等の囲み数字を含む)で始まる行もスキップ |
| 感嘆符・疑問符の後はスペース | `！？!?` の後にスペースを挿入(全角/半角を選択)。行末・閉じカッコ直前には挿入しない |
| 英単語の前後に半角空白挿入 | かな・漢字と英単語の境界に半角スペースを挿入 |
| アラビア数字の前後に半角空白挿入 | かな・漢字と数字の境界に半角スペースを挿入 |
| カッコ内側に半角空白挿入 | カッコの直後と閉じカッコの直前に半角スペースを挿入。例外カッコ(デフォルト `（）【】「」『』｛｝`)は対象外 |
| 二連続の空白削除 | 連続する空白を1つに統合(全角/半角を個別指定) |
| 行末トリミング | 行末の空白を削除 |
| 会話末尾の句点削除 | `「…。」` → `「…」` のように、閉じカッコ直前の句読点を削除(`。、，．` を個別指定) |

字下げの例外文字とカッコの例外は、入力欄で自由に変更できます。

## 機能

- **ライブプレビュー** — 原文の入力やルール変更に合わせて整形結果を即時表示
- **貼り付け時の改行補正** — 特殊な改行コード(U+2028等)を自動で通常の改行に統一。コピー元によって改行が失われる場合も、クリップボードのHTML情報から行構造を復元
- **ダークモード** — ヘッダー右上の「☾ 夜 / ☀ 昼」ボタンで切替
- **設定の自動保存** — ルールのチェック状態・例外文字・表示モードをlocalStorageに保存し、次回起動時に自動復元
- **文字数カウント** — 原文・整形後それぞれの文字数を表示
- **補助ボタン** — 貼り付け / クリア / コピー / 全選択 / 全解除

## 動作環境

- モダンブラウザ(Chrome / Edge / Firefox / Safari の最新版)
- インストール不要・ネット接続不要(`file://` で開いてそのまま動作します)
